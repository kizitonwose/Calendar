## Рабочий календарь 1.6.0-beta.2

### Что нового

- В настройках оформления календаря доступны шесть тем. При обновлении сохраняется привычный вид. Синие ленты соединяют соседние рабочие дни, в пастельной теме даты выделены цветными кругами, в комиксе смены нарисованы в облачках, а в граффити — на ярких мазках. В офисной теме рабочие дни отмечены бумажными стикерами четырёх форм с рукописными цифрами.
- Приложение проверяет опубликованные версии по открытому файлу релизов. Эта проверка работает и при ограничении запросов к API GitHub. При возвращении из фона календарь повторяет проверку с учётом часового интервала.
- Ввод часов, выплат, будильники и долгие нажатия работают во всех темах.

### Установка

Скачайте `WorkCalendar-1.6.0-beta.2.apk`. Это отдельное тестовое приложение, которое можно установить рядом со стабильным.
